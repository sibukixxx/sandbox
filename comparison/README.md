# 言語横断比較 (ブログ・比較サイト用素材)

各言語ディレクトリの `docs/` は「1 言語を深く」、この `comparison/` は「同じテーマを 7 言語横並びで」まとめる。
学習ブログや比較サイトの記事は、ここのファイルをそのまま下書きにできるように書いてある。

## 比較の軸 (全ファイル共通)

各テーマのファイルは、次の順で書く。記事化するときも同じ順で並べれば読める。

1. **一覧表**: 7 言語 × 比較軸 (2〜5 軸)。結論を先に見せる
2. **言語ごとのコード**: 同じ題材 (`sign` / `fizzbuzz` / `Shape` など) で最小コード。動作確認済みのものは `examples/` へのリンク
3. **違いの考察**: 「なぜそう設計されているか」を 3〜5 項目
4. **どれを選ぶか**: 用途別の推奨

## 題材の統一

比較しやすいように、全言語で同じ題材を使っている。

| 題材 | 内容 |
|---|---|
| `sign(x)` | 正 / 負 / 0 を文字列で返す。if-else 式の最小例 |
| `fizzbuzz(n)` | 複数条件の組み合わせ。タプル match があるかどうかで書き方が変わる |
| `Shape` (Circle / Rect) | 代数的データ型 + match、モジュール分割の題材 |
| `checkedDiv` / `averageOfTwo` | Option 相当の扱い方 |
| `Meters` | 別モジュールの小さな型 (newtype) |

## 記事化のルール

- コードは `examples/` から **コピーせず参照する**。修正が入ったときに記事と食い違わないようにするため
- 動作確認していない言語 (Verse) は、記事でも「未確認」と明記する
- 比較表の ✅ / ❌ は「できる / できない」ではなく、「自然に書ける / 回り道が要る」の意味で使う

# 00. なぜ今 MoonBit を学ぶのか

## 位置づけ

2022 年に IDEA (深圳) の張宏波氏 (ReScript の作者) が始めた、WASM を第一のターゲットとして設計された言語。
OCaml 系の型推論と Rust 風の構文を持ち、コンパイラ・ビルドツール・テスト・フォーマッタ・LSP を最初から一体で提供する。

## 差がつくポイント

- **WASM の生成物が小さく速い**。wasm-gc を早期採用し、ブラウザ・エッジ・プラグイン基盤 (Extism など) で「JS の次」として注目されている。
- **JS / ネイティブにも同じコードから出力**できる。1 つのライブラリをブラウザとサーバの両方で使える。
- **テストがソースに書ける** (`test { }` ブロック、スナップショットテスト `inspect`)。テストを書くコストが極端に低い。
- **ツールチェインが一体**。`moon` だけでビルド・テスト・整形・依存管理が済み、環境構築で迷わない。
- 2024〜2025 年に AI コーディング向けの整備 (ドキュメント、エラーメッセージ) を強く推しており、LLM に書かせやすい言語として設計されている。

## 向いている用途 / 向いていない用途

| 向いている | 向いていない |
|---|---|
| ブラウザ / エッジで動く計算ロジック | 既存の巨大エコシステムが必要な業務アプリ |
| プラグインシステムの実装言語 (WASM) | OS レベルのプログラミング |
| 小さく速いライブラリを複数プラットフォームへ配布 | 安定した言語仕様が前提の長期案件 (まだ変化中) |

## 他の言語との比較

Rust で `wasm32-unknown-unknown` 向けにビルドすると所有権と `wasm-bindgen` の学習が必要だが、MoonBit は GC 付きなので「TypeScript を書く感覚」で WASM が出せる。
Go の TinyGo や AssemblyScript と比べると、型システム (ADT、パターンマッチ、trait) がはるかに強い。

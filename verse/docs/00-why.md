# 00. なぜ今 Verse を学ぶのか

## 位置づけ

Epic Games が UEFN (Unreal Editor for Fortnite) 向けに 2023 年に公開した言語。
設計は Simon Peyton Jones (Haskell) と Lennart Augustsson が参加しており、**関数論理型** という分類になる。
Epic は将来 Unreal Engine 本体や「メタバース全体のスクリプト言語」にする構想を公表している。

## 差がつくポイント

- **失敗コンテキスト**。条件式は bool ではなく「失敗しうる式」で、`if` / `for` / `<decides>` 関数がすべてこの仕組みの上にある。他の言語にない設計。
- **効果システム**。`<transacts>` (失敗時にロールバック)、`<suspends>` (非同期)、`<decides>` (失敗しうる) を関数の型として持つ。代数的効果の実用版として学べる。
- **トランザクショナルメモリ**。`<transacts>` 内で失敗すると、それまでの副作用が巻き戻る。
- **巨大な実行環境**。Fortnite 上で書いたコードがすぐ「遊べる」し、UEFN 島の収益化という実利もある。

## 向いている用途 / 向いていない用途

| 向いている | 向いていない |
|---|---|
| UEFN でのゲームロジック | UEFN 以外での実行 (現時点で処理系が UEFN 内にしかない) |
| 効果システム・失敗コンテキストという新しい設計思想の学習 | Linux / CI での自動テスト |
| 将来の Unreal Engine スクリプトへの先行投資 | 安定した言語仕様を前提とする案件 |

## 他の言語との比較

Prolog の「失敗とバックトラック」を、静的型付きの手続き型構文に持ち込んだものと見ると分かりやすい。
Koka や Effekt の代数的効果と同じ問題意識だが、Verse はゲームエンジンに組み込まれて実運用されている点が違う。

## このリポジトリでの到達点

- 章 2〜4: デバイス、失敗コンテキスト、データ型
- 章 5: `<decides>` / `<transacts>` / `<suspends>` の効果システム
- 章 6: モジュールとアクセス指定子
